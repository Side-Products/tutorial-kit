# Examples

- [`basic/`](basic/): a loopback-only demo with synthetic data. Start it with `npm run demo`, then follow the
  root README to list, check, and record it. No API keys are needed until narration.
- [`faceless/`](faceless/): flows demonstrating a public website tour and locating API documentation. These
  visit a live website, whose content and selectors can change. They do not require authentication. Configure
  your own voice for narration.

For your own product, start with
[`templates/tutorials.config.example.mjs`](../templates/tutorials.config.example.mjs). Keep recordings,
generated output, and credentials out of Git.
